# Security policy

## Supported versions

Security fixes are made against the latest published release. Older versions may not receive updates.

## Reporting a vulnerability

Please do not post credentials, private checkpoint files, or exploitable details in a public issue. Use GitHub's private vulnerability reporting for this repository when it is enabled. If private reporting is unavailable, contact the repository maintainer privately before public disclosure.

SwitchShelf is designed to stay local and read-only with respect to the project. Reports can still contain filenames, branch names, and user-authored notes; review them before sharing.
